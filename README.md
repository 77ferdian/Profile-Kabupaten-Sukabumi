# Profile Kabupaten Sukabumi

Situs profil daerah statis yang menampilkan informasi lengkap tentang Kabupaten Sukabumi, Jawa Barat, Indonesia. Proyek ini menghadirkan tampilan yang modern dan informatif untuk memperkenalkan sejarah, geografis, serta destinasi wisata alam yang dimiliki wilayah ini.

## Overview

Website ini dirancang untuk menampilkan profil Kabupaten Sukabumi secara singkat namun komprehensif, mencakup:

- Hero section dengan visual alam dan branding daerah
- Sejarah berdirinya Kabupaten Sukabumi
- Informasi geografis dan letak wilayah
- Destinasi wisata alam unggulan
- Informasi umum daerah yang ditampilkan dengan layout yang rapi

## Features

- Desain landing page yang responsif
- Layout semantik menggunakan HTML5
- Styling modern dengan CSS3 dan custom properties
- Integrasi Google Fonts untuk estetika typography
- Menampilkan informasi wisata alam dan profil daerah secara menarik

## Getting Started

1. Clone repository ini:

```bash
git clone https://github.com/77ferdian/Profile-Kabupaten-Sukabumi.git
```

2. Masuk ke direktori proyek:

```bash
cd Profile-Kabupaten-Sukabumi
```

3. Buka file `index.html` di browser pilihan Anda.

Anda juga dapat membuka project ini menggunakan ekstensi Live Server di VS Code agar lebih nyaman saat pengembangan dan preview.

## Run Information

Proyek ini merupakan website statis, sehingga tidak memerlukan proses build atau install dependency tambahan. Cukup buka file `index.html` secara langsung atau jalankan melalui local web server.
